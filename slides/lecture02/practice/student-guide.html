Understanding missing-value behavior

In our tennis fixture, 0 Grand Slam titles is an observed value. An unknown or unrecorded title count would be missing. Missing is not zero. Empty text is not automatically missing either. Detecting missing values and deciding what to do about them are separate tasks. Use the explicit missing-value test, not equality to NA/NaN.

Python

sample = np.array([2, np.nan, 4])
np.isnan(sample)

R alternative

sample <- c(2, NA, 4)
is.na(sample)

Python

np.mean(sample)
np.nanmean(sample)
pd.Series(sample).mean()
pd.Series(sample).mean(skipna=False)

R alternative

mean(sample)
mean(sample, na.rm = TRUE)

For 2, missing, 4: ordinary R/NumPy mean is missing. The explicit missing-skipping mean is 3, with denominator 2. A pandas floating-point Series mean skips missing values by default here; skipna=False instead propagates missingness. Always identify the library and denominator. A default is not a justification.
