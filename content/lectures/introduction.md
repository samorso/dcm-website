**First period — why this course, and what it is for.** Where AI has moved the
effort in data work, why code literacy and validation matter more rather than
less, and the map the whole semester follows: code literacy → data → engineering
→ production, with AI throughout.

**Second period — how the course runs.** The dated roadmap, what you should be
able to demonstrate by December, the two homeworks and the group project,
expectations around AI use, the tool stack, and a live preview of the working
loop with a coding agent.

## The agent preview

The demonstration follows the loop you will use all semester, on a small
synthetic orders project:

1. **Inspect before delegating.** Start the agent in the project folder and ask
   it to explain the project *without changing anything*. Check the explanation
   against the files.
2. **Establish a baseline.** Run the project and note what it currently prints.
3. **Specify one bounded change.** Say exactly what may be edited and what must
   not be touched, and ask for a plan before any edit.
4. **Inspect the diff.** Only the intended change; no altered data, no weakened
   checks, no unrelated files.
5. **Run and verify independently.** Recompute the result by hand.

<div class="key">
A program that runs is not a program that is correct. The independent check is
the point of the exercise, not a formality at the end of it.
</div>
